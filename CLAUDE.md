# Claude Instructions — Point Numera

This repository belongs to Point Numera, a fractional CFO consultancy based in Amsterdam, NL.

**Before working on anything in this repo, read the build knowledgebase:**

→ [`kb-build.md`](./kb-build.md)

It contains colors, fonts, CSS variables, UI patterns, site architecture, section background rules, embed strategy, and all visual conventions. Do not write any code or make any design decisions without reading it first.

For brand voice, ICP, and content work, see [`kb-content.md`](./kb-content.md) — but that file is not needed for building.

## Quick reference
- Primary: `#0E4F47` · Accent: `#F4ECBD` · Cards: `#A4D6A4` · Dark: `#0a0f0e`
- Headings: Ancizar Sans · Body: PT Sans
- Sections alternate backgrounds — never two consecutive sections the same colour
- Tools embed via iframe on dark background — no white backgrounds in tool UIs
